# Shamin Azaz - Personal Portfolio & Interactive Chatbot

This repository contains the source code for the personal portfolio website of **Shamin Azaz**, showcasing professional experience, educational credentials, featured technical projects, an interactive chatbot, and QR code access.

## Features
- **Responsive Layout**: Designed with HTML5, CSS3, and JavaScript for seamless display across mobile, tablet, and desktop screens.
- **Interactive Chatbot**: Built with a custom keyword-matching NLP response engine to answer FAQ queries regarding background, skills, and security clearances.
- **QR Code Integration**: Uses `qrcode.js` to dynamically generate a QR code linking directly to the live portfolio site.
- **Resume Integration**: Includes a downloadable PDF copy of Shamin Azaz's professional resume.

## How to Navigate the Site
1. **Home**: Overview and clearance status badge.
2. **About**: In-depth breakdown of core technical skills and academic background at Bowie State University.
3. **Projects**: Links to GitHub repositories showcasing enterprise networking and automated scripting projects.
4. **Resume**: View details and download a PDF copy of the resume.
5. **Contact**: Form to send direct queries.

## Chatbot Implementation Details
The chatbot is implemented in `script.js`. It listens to user queries, processes the string with basic Natural Language Processing (NLP) pattern matching, and provides instant responses tailored to common hiring manager questions.
